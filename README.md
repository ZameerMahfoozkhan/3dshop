# StuffForge — Futuristic & Emerging 3D Printing Studio & Product Lab

Futuristic & emerging 3D printing studio and product lab based in Greater Noida, UP, delivering ready-made functional essentials and custom CAD manufacturing across India.

## Features
- **Ready-Made Products**: Curated catalog of desk accessories, organization tools, home decor, and personalized gifts.
- **Custom Design + Print**: End-to-end prototyping and CAD modeling from sketches, ideas, and references.
- **Direct 3D File Manufacturing**: Fast FDM production from user-uploaded STL, 3MF, OBJ, and STEP files.
- **Local Express Dispatch**: Rapid local turnaround and courier coverage across Greater Noida & Delhi NCR, with pan-India courier delivery.
- **Direct WhatsApp Ordering**: Human-reviewed, frictionless instant quotation and ordering flow.

## Tech Stack
- Semantic HTML5 & Responsive Vanilla CSS
- Modular Vanilla JavaScript (ES6+)
- Zero unnecessary dependencies or complex build steps

## Local Development
To preview the website locally:
```bash
# Using Python
python -m http.server 8080

# Or using Node.js http-server
npx http-server . -p 8080
```
Open `http://localhost:8080` in your browser.
